# 修仙家族 · Cultivation Family

An HTML5 idle game about building a cultivation dynasty. Gather Qi, recruit family members, breakthrough realms, unlock family traits, and survive random events.

## Features

- **Dark mystical UI** — gold and jade accents, smooth button animations, floating "+Qi" text on click
- **Family Heritage (家族天賦)** — choose 1 of 3 random traits after each breakthrough
- **Random Events (突發事件)** — good and bad events every 15–30 seconds with toast notifications

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

## Build

```bash
npm run build
npm run preview
```
