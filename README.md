# 青雲世家 · Cultivation Family

A polished browser idle game about building an immortal cultivation lineage. Gather Qi, recruit family members, guide the Ancestor through breakthroughs, inherit permanent bloodline traits, and react to changing family fortunes.

## Features

- Responsive dark mystical interface with jade and gold accents
- Active Qi gathering and passive generation from family members
- Seven cultivation realms with increasingly demanding breakthroughs
- Eight permanent Family Heritage traits that change the game economy
- Random good and bad family events every 15–30 seconds
- Animated event notifications, interaction feedback, and cursor-positioned Qi text
- Automatic saves and up to eight hours of offline Qi generation

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

Game progress is stored in the browser's `localStorage`; no account or backend is required.
