# 修仙家族 (Cultivation Family) - 仙道傳承模擬

一個高品質、現代暗黑仙俠風（Mystical Dark Mode）的 HTML5 放置/養成網頁遊戲。

## ✨ 遊戲特色 (Features)

### 1. 唯美暗黑仙俠 UI / 現代視覺特效 (Mystical Dark UI & VFX)
- **玄金、翡翠玉石、紫微帝氣** 的沉浸式道家仙俠配色。
- 專屬 CSS 平滑 Hover & Click 縮放發光動畫。
- **閉關修煉浮空文字粒子**：點擊「閉關修煉 (Gather Qi)」時，於鼠標位置即時生成 `+10 靈氣 (Qi)` 飄升漸變消散特效。
- **萬載紀事古卷 (Ancient Scroll Chronicle Log)**：宣紙暗紋與金邊捲軸質感，實時記錄家族大事與天道因果。
- **靈氣粒子流動背景**：Canvas 即時生成天地靈氣與星辰光暈。
- **內置 Web Audio 五音法樂合成器**：古箏、銅磬、九霄仙鐘與破境天音。

### 2. 🧬 家族傳承天賦系統 (Family Heritage Traits)
- 老祖突破（如築基、金丹、元嬰至真仙）時，觸發天地感應彈窗，自選 **3 選 1 家族天賦**。
- 包含三大核心天賦及衍生神話血脈：
  - **「多子多福」**：招募子嗣/族人靈氣消耗減少 20%。
  - **「天靈根血脈」**：每位族人基礎產出靈氣提升 +50%。
  - **「勤能補拙」**：手動點擊「閉關修煉」靈氣收益翻倍（2x Qi）。
  - **「丹道世家」**、**「氣運所鍾」**、**「龍脈祖地」**、**「道心澄澈」** 等。
- 啟用之天賦即時列入「🧬 家族傳承」面板並全局計算數值加成。

### 3. ⚡ 家族突發事件系統 (Random Events & Sliding Toast)
- 每 15 至 30 秒自動觸發天道機緣（50% 機率）。
- 頂部專屬半透明金玉雙色 Toast 通知滑動降下，3 秒後自動隱退。
- 吉祥事件（百年靈芝、良緣聯姻、老祖頓悟、散修歸附、天外隕鐵）與凶險厄運（仇家偷襲、走火入魔、地脈震盪），族人人數設有保底防護（不低於 1）。
- 所有事件實時記載於家族紀事日誌。

### 4. 🏛️ 洞天福地與族人譜牒
- 聚靈靈泉、百草靈田、八卦煉丹閣、藏經閣秘藏、天元靈石礦脈、九天通神祭壇。
- 族人譜牒記錄歷代弟子世代、靈根（天靈根/異靈根/雙靈根等）、修為及忠誠度。

## 🚀 本地運行 (Getting Started)

```bash
# 啟動開發伺服器
npm run dev

# 構建生產版本
npm run build
```
