語速約每分鐘 430 字，全稿約 **3 分 20 秒**（加咗製作 workflow）。PowerPoint / Keynote 開「講者備註」即可。

## 0:00–0:18　封面

大家好。呢個係**教父世家**。

唔係又一個點擊升級遊戲。你入去唔係一個數字，而係一間住喺青嵐山門嘅修仙世家。

你係**天道**：睇住人長大、結緣、走火、身死道消；間中伸手改命。

而家就可以玩：`yip-lgtm.github.io/family`  
源碼喺 `github.com/yip-lgtm/family`

今日三分鐘：做咩、**點做出嚟**、點玩。

---

## 0:18–0:38　唔係點擊遊戲

傳統放置遊戲：你係農夫，囤資源、買升級、睇數字。

教父世家唔係。畫面中間個靈樞可以聚氣，但真正玩法係右邊同下面：一班有根骨、心性、境界、壽元、心情、關係網嘅人。

你用業力**賜福、降天劫、種心魔**、或者指派去丹房藏經閣。

你少出手，山門自己過月。你出手，就係改命。

---

## 0:38–0:58　天道介面

介面就係天道嘅工作台。

上面係曆法、靈氣、業力。時間可以停、可以快轉。

中間係山門地圖：人會自己去後山冒險、丹房煉丹、藏經閣讀書、雲市交易。

點一個人，睇根骨心性境界心事記憶。

天道三鍵好貴：賜福八業、天劫十二、心魔十、指派三。

左邊傳承：家訓、老祖突破、揀天賦。金丹同元嬰會金光一閃。

---

## 0:58–1:18　活人，唔係數值

開局六個人，全部寫咗性格，唔係隨機數。

**青玄機**鎮山門，金丹後期——冇老祖就冇世家。  
**沈清梧**穩、顧家。**葉疏影**冷、準、同清梧有舊怨。  
**白無塵**外來、身世成謎。**蒼小魚**貪生識時務。**嵐七七**細、靈、成日問不該問嘅嘢。

每個月佢哋自己揀修煉、冒險、煉丹、讀書、交際、交易或者歇息。會死。死咗，功法可以留低。

---

## 1:18–1:42　編劇組 + OpenRouter

呢度係產品最特別嘅一層：**編劇組**。

結構致敬《教父》三部曲：血色開端、雙生歲月、最後輓歌。致敬節奏同主題，**唔抄對白，唔抄人名**。

每兩個月自動一場戲。接 OpenRouter 免費路由；API Key 只存在你部瀏覽器。

冇 Key 就用**劇組代班**——仍然有完整場面。戲會寫入心事同關係。

---

## 1:42–1:55　金漆山門

美術全部 CSS 同 Canvas，無外部圖。音效用 Web Audio 合成。背景音樂係嗶哩官方嵌入，可縮成一條。技術棧：Vite、原生 JS。

---

## 1:55–2:20　遊戲製作 workflow

製作**唔係先畫皮**。

一、立意：玩家係天道，唔係農夫。  
二、規則：`world.js` 月結、根骨、壽元、業力、死亡。  
三、編劇：`screenplay.js` 三幕 + 劇組代班，戲寫入心事。  
四、皮與聲：CSS、Canvas、Web Audio、嗶哩嵌入。零外鏈圖。  
五、試玩：Vite 開 `/family/`，改完即睇。  
六、出貨：`npm run build`，推 `gh-pages`，就係 `github.io/family`。

---

## 2:20–2:42　工程回路

六個檔，冇框架組件庫。

`world` 管規則，`screenplay` 管戲，`main` 管天道介面，`style`、`fx`、`audio` 管現場。

每日：**改規則或文案 → `npm run dev` → 睇一場戲 → commit**。  
出貨：**build → 推 gh-pages**。  
紅線：唔偷嗶哩音、唔抄教父對白、Key 唔上伺服器。劇組代班永遠兜底。

---

## 2:42–3:05　而家點玩

四步，唔使註冊。

一：打開 `yip-lgtm.github.io/family`，撳「承天命」。  
二：點沈清梧或者葉疏影。  
三：開時間，等編劇組兩場。  
四：只用一次天道，然後停手。

---
